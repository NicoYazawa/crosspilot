## Step 2 — SSE 可恢复客户端

**创建文件**：`frontend/src/lib/sse/{types,cursor,hmac,client}.ts` + 4 个测试文件

**关键设计**：
- 用 fetch + ReadableStream 而非 EventSource（支持 HMAC 请求头）
- 跨 run 拒绝：`bindToRun` 校验 cursor.runId === targetRunId
- seq 缺口拒绝：`ev.seq !== lastSeq+1` → `onError(gap)` + close
- Polling fallback：流尾启动 `setInterval` 轮询 `/agui/runs/{id}`，见到 TERMINAL_KINDS 停止
- 空 baseUrl fallback：`new URL(path, window.location.href)` 避免 `Invalid base URL`

**自测**：`cd frontend && npm run test -- sse`（5 用例全绿）

## Step 4 — A2UI v0.9 渲染器

**创建文件**：`frontend/src/features/a2ui/{schema,registry,Renderer}.tsx` + 9 个组件 + `a2ui.test.tsx`

**三层防线**：
1. **类型层**：`z.enum([...])` 闭合 9 种组件 type
2. **运行时层**：Zod schema 三报文校验 + 组件注册表；未注册的 type → `A2UIRenderError` 灰卡
3. **ESLint 层**：`react/no-danger` + `no-restricted-syntax` 禁用 `dangerouslySetInnerHTML`

**自测**：`cd frontend && npm run test -- a2ui`（8 用例全绿）

## Step 5 — 三件套面板

**创建文件**：`frontend/src/features/observability/{ReplayView,DiffView,CostView,ABView,MetricsGrayCard}.tsx` + 4 个测试

**要点**：
- ReplayView：时间线 + ⛔ `REDACTED` 徽标
- CostView：总成本 / unpriced / 总调用 cards；unpricedCount > 0 顶部 ⚠️ Banner；Recharts BarChart tokens 分类
- DiffView：added=绿 / removed=红 / changed=黄 / unchanged=灰 badge
- ABView：4 列（Calls / P95 / Cost / Unpriced），**不显示 judge_score**；表头注释「LLM-judge 未启用」
- MetricsGrayCard：503 → 「未启用」灰卡

**自测**：`cd frontend && npm run test -- observability`（12 用例全绿）

## Step 6 — useOptimistic 集成

**创建文件**：`frontend/src/features/shop/{ShopView,useChat}.tsx` + `useChat.test.tsx`

**设计要点**：
- 仅 ShopView 用户消息用 `useOptimistic`（G1 可独立测量）
- `addOptimistic` 后通过 `performance.now()` 报告 `crosspilot.optimistic.add_latency_ms` 指标
- `a2uiMessages` 状态独立追踪，透传给 `A2UIRenderer`
- `send` 是 async，`onSubmit` 用 `.then(() => setQuery(''))` 清空输入框

**G1 验收**：`cd frontend && npm run test -- useChat`（断言 `addOptimistic` 延迟 < 16ms）
