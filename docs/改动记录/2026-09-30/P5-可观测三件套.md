## 关键设计决策（落地版）

### D1 — 写路径脱敏

Emitter 内部同步调用 `Redactor.Apply(ev.Payload)`，落 `SinkRecord.PayloadRedacted`。reader 拿到的是已脱敏 JSON，不会因 reader 升级而漏掉新模式。

### D2 — 异步有界队列，绝不阻塞 Agent

```
orchestrator.Run → Bridge.forward → J.Append (同步)
                            └→ Emitter.Emit (同步只塞 channel)
                                  └→ Run goroutine: 批量 flush
                                        └→ sink.Append (失败 → dropped)
```

测试 `TestF6_EmitDoesNotBlockWhenQueueFull` 守门。

### D3 — 接口分层（arch 干净的副作用）

为了不让 application 层 import infra 层（arch 规则）：

| 类型 | 归属 | 备注 |
|---|---|---|
| `Sink` 接口 / `SinkRecord` | `agent/observability` | 消费者侧定义接口 |
| `MemorySink` | `agent/observability` | 测试 helper；agent 可实现自己的接口 |
| `Redactor` 接口 | `agent/observability` | 同上 |
| `Redactor` 实现 | `infra/observability` | 默认规则集（7 类） |
| `Metrics` | `agent/observability` | expvar 计数器 |

未来 Postgres sink 适配器在容器层（`internal/container`），它可以同时 import 两侧——assembler 是唯一允许跨层的角色。

### D4 — 内容寻址 blob

`PayloadSHA256` 必存；`PayloadSize` 是原始长度；`PayloadRedacted` 是脱敏后 JSON。生产可设开关只存 sha256（节省 90%+ 存储），但默认存已脱敏 JSON 以便 F1 回放。

### D5 — 成本归因：版本化价格表

`internal/pricing/`：四家 provider × 四类 token_kind 的三维表。空表 / 文件不存在 → 全 unpriced，不静默按 0 计。

### D6 — A/B 骨架

`ExperimentStore` 接口 + `UseCases.ExperimentArms` 聚合查询。`Judge` 接口 + `StubJudge` 默认返回 `ErrJudgeNotImplemented`——前端面板降级为「未启用」。

### D7 — 回放 API 直接复用 P4 journal

`application/observability.JournalStore` 是窄端口，只暴露 `Append/Since/LastSeq`。生产注入 `agui.JournalStore` 的 Postgres 实现。
